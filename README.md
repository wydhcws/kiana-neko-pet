**一只会说话、会唱歌、会陪你工作的二次元 3D 桌宠**

## 这是什么

一个站在你屏幕右下角的透明小窗口，里面住着一只猫耳琪亚娜。她会：

- 用**眼睛跟着你的鼠标**，眨眼、呼吸、耳朵抖、尾巴摇
- 被摸头会眯眼脸红打呼噜，被戳尾巴会炸毛，被拖来拖去会晕
- 用 **AI（DeepSeek）按人设实时生成台词**，也能打字跟她聊天
- 有**二次元少女配音**，说话时嘴型跟着音量开合
- 你放歌时**逐句显示歌词跟着唱**，还会对口型摇摆（macOS）
- 整点报时、喝水提醒、番茄钟、久坐提醒、节日台词、好感度养成
- 3 分钟没人理她会睡着，点一下就醒

所有**音效都是 WebAudio 实时合成**的（喵叫、呼噜、铃铛、跳舞小曲）。
内置的 **Q 版猫娘是纯代码程序化建模**——几何体、卡通着色、描边、表情贴图全部由代码生成，
不含任何官方素材。此外还内置了四个 MMD 模型（薪炎律者、终焉律者、崩坏歌姬、咚琪小礼裙），见下文说明。

## 安装

### 直接下载（推荐）

到 [Releases](../../releases) 下载对应系统的安装包：

| 系统 | 文件 | 说明 |
| --- | --- | --- |
| macOS (Apple Silicon) | `kiana-neko-pet-x.x.x-arm64.dmg` | M1/M2/M3/M4 |
| macOS (Intel) | `kiana-neko-pet-x.x.x-x64.dmg` | |
| Windows | `kiana-neko-pet-setup-x.x.x.exe` | 安装版 |
| Windows | `kiana-neko-pet-x.x.x-portable.exe` | 免安装，绿色版 |

> 安装包文件名用的是英文（GitHub 对中文文件名的支持有问题，下载时会丢字），
> 装进电脑后应用名、快捷方式仍然是「琪亚娜猫娘」。

> **macOS 首次打开提示「无法验证开发者」**：安装包未做 Apple 公证（需要付费开发者账号）。
> 右键点击 App → 打开 → 再次点「打开」即可；或执行
> `xattr -cr "/Applications/琪亚娜猫娘.app"`。

### 从源码运行

```bash
git clone https://github.com/wydhcws/kiana-neko-pet.git
cd kiana-neko-pet
npm install
npm start
```

macOS 上如果要用**跟唱音乐**功能，额外编译一次原生小工具
（需要 `xcode-select --install` 和 `brew install cmake`，依赖已随仓库提供）：

```bash
npm run build:native
```

Windows 上不需要这一步，跟唱功能会自动隐藏，其余功能完全正常。

## AI 对话（DeepSeek）

闲聊台词由 AI 按琪亚娜人设实时生成，会结合当前时间、星期、节日、正在听的歌、
你刚才对她做了什么、连续用电脑多久。按 `⌘⇧J` / `Ctrl+Shift+J` 可以直接打字聊天，
她记得最近几轮对话，回复会带情绪动作（开心、害羞、生气、惊讶…）。

配置方式：设置环境变量 `DEEPSEEK_API_KEY`，启动一次后会用系统钥匙串（Electron `safeStorage`）
加密保存到本地，之后不依赖环境变量也能用。Key 只在主进程使用，不会进入页面。

```bash
export DEEPSEEK_API_KEY='sk-你的key'   # macOS/Linux
setx DEEPSEEK_API_KEY "sk-你的key"     # Windows
```

没配置 Key 也能用——会退回到约 180 句手写台词（含节日、深夜、周末、久坐等情境）。

## 配音

台词有二次元少女配音（微软 Edge 在线语音合成），三种音色可选：
元气少女 / 温柔少女 / 软萌台湾腔。首次需要联网，合成后缓存在本地，之后离线也能播；
断网时自动退回打字音效。说话时**嘴型跟着配音音量实时开合**。

## 跟唱音乐（仅 macOS）

波点音乐、Apple Music、Spotify 等播放器放歌时，她会跟着唱：报歌名 → 气泡里逐句显示歌词
→ 按音节对口型 → 身体摇摆 → 每三句闭眼唱一句。暂停就停，切歌会说「下一首是《…》！」

歌词来源：先找 `~/Music/琪亚娜歌词/` 里的 `.lrc`（文件名包含歌名即可，
如 `晴天 - 周杰伦.lrc`），再查公开歌库 [LRCLIB](https://lrclib.net)，结果缓存本地；
中文歌找不到同一歌手时，会用歌名相同、时长相差 3 秒内的翻唱版歌词。

### 舞步模式

默认开启（右键 → 跟唱音乐 → 舞步模式）。放歌时她会**按节拍跳舞**，同时照常显示歌词、对口型。
舞步是代码生成的，不需要 VMD 动作文件：

- **14 个舞步**：律动、侧步、扭胯、拍手、招财猫、举手摇摆、波浪手、指向、比心、抬膝、
  下蹲起身、转圈、甩头发、定格，都可以左右镜像
- **按歌词分段编舞**：每 8 拍一小节，重复出现的句子判为副歌（用高能量舞步），
  主歌用轻松舞步，前奏/间奏律动，结尾定格；小节起点对齐第一句歌词
- **BPM** 由 DeepSeek 按歌名估计并缓存（没配 AI 时默认 120）；太快的歌跳半拍、太慢的跳双拍
- 同一首歌的编舞是固定的（随机种子 = 歌曲 id），换首歌就换一套
- 「**舞步预览**」可以不放音乐直接试跳 40 拍

> **为什么只有 macOS**：读取「正在播放」依赖 macOS 的 MediaRemote 私有框架，Windows 无对应接口。
>
> **关于 macOS 15.4+**：Apple 从 15.4 起限制第三方进程直接访问 MediaRemote（会静默返回空数据）。
> 本项目通过 [mediaremote-adapter](https://github.com/ungive/mediaremote-adapter)（BSD-3-Clause）
> 借由系统自带的 `/usr/bin/perl` 间接读取，在新系统上依然可用。

## 模型

右键 → **模型** 可以切换形象：

| 选项 | 说明 |
| --- | --- |
| **Q 版猫娘** | 内置，纯代码程序化生成，有猫耳、12 节会摆的尾巴、铃铛、呆毛 |
| 薪炎律者 | MMD 模型，**已内置** |
| 终焉律者 | MMD 模型，**已内置** |
| 崩坏的歌姬 World Diva | MMD 模型，**已内置** |
| 咚琪小礼裙 | MMD 模型，**已内置** |
| **模组库（按人物选）** | 加载一整个模型合集，按「游戏 ▸ 人物 ▸ 模型」逐级选 |
| 选择其他 PMX 模型… | 任意单个 MMD 模型都能加载 |

**模组库**：如果你有成批下载的模型合集，用「模型 → 模组库 → 加载模组库文件夹…」指定根目录即可，
程序会自动扫描并按人物分组，不要求固定的目录结构。比如下面这样当然没问题：

```
<模组库根目录>/
└── 崩坏3/                       ← 游戏
    ├── 琪亚娜/                   ← 人物
    │   ├── 琪亚娜—终焉律者/        ← 一套模型
    │   │   └── 琪亚娜.pmx
    │   └── 琪亚娜夏装/
    └── 爱莉希雅/
```

目录不一定要三层——**扫描器会自己判断结构**：「游戏/人物/模型」「人物/模型」，
甚至模型文件夹全部平铺也能认（靠名字的公共前缀把同一人物的多套模型聚到一起）。
扫描时会自动跳过武器、坐骑等道具 pmx，同一套里的多个版本（长发/短发、黑裙/白裙）都会列出来。
切换模型后窗口比例会自动适配，不用手工调参。

**换角色 = 换个人**：选了别的角色后，她的台词、AI 对话和动作都会跟着那个角色走。

| 跟着变的 | 说明 |
| --- | --- |
| 自称 / 称呼你 / 口癖 | 布洛妮娅自称「布洛妮娅」，星穹铁道的角色叫你「开拓者」 |
| AI 人设 | prompt 按角色重写，气泡署名也跟着换 |
| 固定台词 | 御三家（琪亚娜 / 芽衣 / 布洛妮娅）都有整套专属台词；其余角色在通用台词基础上替换上面那三类用语 |
| 动作幅度 | 芽衣 0.85、布洛妮娅 0.75、丽塔 0.8…… 沉稳的角色动作收敛一些 |

`characters.js` 里只为有把握的角色写了简短性格，没收录的角色**不编造设定**，
而是让 AI 按它自己对该角色的了解来演。选回琪亚娜时，台词、人设和动作与原来**一字不差、逐帧一致**。

MMD 模型用骨骼驱动动作、用模型自带表情，头发/披风/裙摆由 Ammo 物理驱动。
**动作风格**有三档：平稳（默认）/ 轻微颤动 / 原样（活泼，头发会细细颤动）。

### ⚠️ 关于 MMD 模型文件

安装包和仓库里**内置了四个 MMD 模型**：薪炎律者、终焉律者、崩坏的歌姬 World Diva、咚琪小礼裙。

这些模型由社区的大佬们制作（模型作者：**神帝宇**，主页：<https://www.aplaybox.com/u/359396473/model> ），
角色版权归 miHoYo。本项目是免费、非商业的同人作品，内置它们只是为了开箱即用、图个方便。
如果模型作者或 miHoYo 觉得这样不妥，欢迎开 issue 联系我，我会第一时间把对应模型从仓库和安装包撤下。

当然你也可以用自己的模型：「模型 → 模组库」可以批量导入整个文件夹，
「选择其他 PMX 模型…」可以指定单个文件，程序都会自动适配。详见 [`models/README.md`](models/README.md)。

**不下载任何额外模型也不影响使用**——Q 版猫娘和四个内置模型都已开箱即用。

## 自己打包

```bash
npm run dist:mac     # macOS: dmg + zip (arm64 / x64)
npm run dist:win     # Windows: NSIS 安装包 + 免安装版
npm run pack         # 只打目录，不生成安装包，用于本地验证
```

> Windows 安装包建议在 Windows 上构建（或用仓库里的 GitHub Actions）。
> 仓库已配置 `.github/workflows/release.yml`：推一个 `v*` tag 会自动在
> macOS 和 Windows 上分别构建并发布到 Releases。

```bash
npm version patch && git push --follow-tags   # 触发自动发版
```

## 项目结构

```
main.js                  主进程：透明窗口、鼠标穿透、菜单/托盘、app:// 协议、
                         模型注册表、设置持久化、跟唱、AI/配音/歌词 IPC
preload.js               contextBridge 暴露白名单 IPC
voice.js                 Edge TTS 配音合成 + 哈希缓存 + 后台预合成队列
lyrics.js                歌词：本地 .lrc → LRCLIB，LRC 解析与缓存
modlib.js                模组库扫描：自动识别目录结构、按人物归类，剔除武器道具
characters.js            角色设定：换模型时的自称/称呼/口癖与 AI 人设
ai.js                    DeepSeek：人设 prompt、情境、聊天记忆、Key 加密保存
src/app.js               渲染进程：场景相机、动作状态机、交互命中、气泡、定时器
src/sfx.js               WebAudio 合成音效 + 配音播放与音量分析（口型）
src/lines.js             约 180 句固定台词、节日、问候
src/dance.js             舞步库（14 个动作）+ 按歌词分段的编舞器
src/avatars/
  chibi-model.js         Q 版程序化建模（几何体、卡通材质、描边、表情贴图）
  chibi.js / mmd.js      两种形象的适配器：统一姿态参数 → 各自骨骼与表情
native/                  macOS「正在播放」读取（跟唱数据源）
scripts/build-native.js  跨平台原生构建脚本（非 macOS 自动跳过）
assets/make-icon.js      应用图标生成器（不依赖图形库，可复现）
```
